# Project Overview Section

## Title: Color Scheme Generator

 A web application that generates harmonious color schemes using the Color API

## Features Section

Multiple color scheme modes (Monochrome, Analogic, Complement, Triad, Quad, etc.)

- Real-time color preview with visual swatches
- Custom seed color selection
- Displays color information (HEX, RGB, color names)
- Interactive and user-friendly interface

## Demo/Screenshot Section

Instructions on how to view the app (open index.html in browser)
Description of what users will see after clicking "Generate Scheme"

## Technologies Used Section

- HTML5
- CSS3 (with gradient backgrounds)
- JavaScript (ES6)
External API: The Color API ([https://www.thecolorapi.com/](https://www.thecolorapi.com/))



## How to Use Section

- Step-by-step instructions:
- Select a seed color using the color picker
- Choose a color scheme mode from dropdown
- Click "Generate Scheme" button
- View the generated color palette
- Check console for API response details



## Project Structure Section

- Brief description of each file:
- index.html - Main markup with form controls
- main.js - API logic and color rendering
- style.css - Styling with gradient background
- README.md - Project documentation
